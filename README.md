Student Management System
  Overview:
      This project is a Student Management System web application built using Spring Boot,
      Thymeleaf, Spring Data JPA, Hibernate, and MVC architecture. 
      It allows users to manage student records efficiently.


Features: 
  Add new students with details like name, email, and course.
  
  View student records in a structured format.
  
  Update student details when needed.
  
  Delete student records easily.
  
  Search functionality to find students quickly.

  Database integration using MySQL.



Technologies Used :
Java (Spring Boot)

Spring MVC (for handling requests)

Thymeleaf (for dynamic HTML rendering)

Spring Data JPA & Hibernate (for database operations)

MySQL(for storing student records)

Bootstrap (for styling and responsive UI)
